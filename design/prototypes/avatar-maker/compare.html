Contrast: all 64 combinations, both sets, both themes

First run: 128 failures, every dark-theme avatar including the mascot's own colours (worst 1.06:1). The cocoa stripes run into the cocoa outline, and on a dark panel that stretch of edge disappears. No disc colour can fix it (it would need to be lighter than the outline and darker than every body at once). Fix: a 1 px sticker edge on dark-theme tokens (--av-halo #9d8d70, an SVG dilate filter), which leaves the drawing and the mascot untouched. After: 0 failures; every dark avatar's edge is 4.27:1 at its worst (the honeycomb's peak), every light one 14.32:1. Full tables: contrast.md (after), contrast-before.md, or run it live.

Existing avatars: how the old keys map

Proposed backfill (old key → colour, cosmetic) for each set. The old client keeps writing the key; a sync trigger derives the parts. A new client writes the parts, and the trigger derives the nearest key so old clients still draw something sensible. Details in the README.
