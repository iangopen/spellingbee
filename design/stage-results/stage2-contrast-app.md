# Contrast baseline: the current app

Generated by `design/harness/measure.mjs` (TARGET=app). The REAL screens (rendered from `src/` by `design/harness`, network modules stubbed), measured the same way as the prototype: every visible text element, control edge and focus ring against the **worst pixel behind it**. Each row is the minimum over desktop and phone. Required: text 4.5:1, large text 3:1, edges and focus rings 3:1.

**727 measured pairs, 265 failing.** 34 focusable controls show focus without an outline (listed at the end). (1600 raw measurements across 64 renders.)
